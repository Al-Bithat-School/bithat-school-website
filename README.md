# Bi’that Group of Schools and Colleges

Responsive bilingual (English/Urdu) public website.

## Included
- Campus profiles linking to official Trust pages
- Admission and WhatsApp contact links
- Student achievements section
- Notices and downloads section ready for approved documents
- Roll-number result lookup interface
- GitHub Pages deployment workflow

Main Trust website: https://albithattrust.org/
Boys Higher Secondary School: https://albithattrust.org/bithat-boys-high-school/
Official school WhatsApp: https://wa.me/923187408699

Important: the result form does not display marks yet. Connect it to the school's verified result database before using it for official results. Campus details and images should be reviewed by the administration before public launch.

To publish, open repository Settings → Pages and choose GitHub Actions as the deployment source if Pages is not already enabled.
